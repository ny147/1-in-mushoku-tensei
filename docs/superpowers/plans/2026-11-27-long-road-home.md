# The Long Road Home implementation plan

Weerawich approved the [design](../specs/2026-11-27-long-road-home-design.md) for implementation on PR #44.

1. Exercise history-based eligibility, manual choices, the due year, capped recovery, travel restrictions, relocation and replay through the public simulation and save loader.
2. Add bounded optional progress to expanded lives. Reuse normal travel pricing, movement and validation. Record actual results with bilingual cards and leave priority events in place.
3. Exercise the story from Optional activities in English desktop and Thai phone-width Chrome using isolated saves. Restore standard CI, verify the final source and run the full suite and production build.
